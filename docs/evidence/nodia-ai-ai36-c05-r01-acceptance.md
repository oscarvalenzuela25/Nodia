## Cobertura del diagnóstico

Se reprodujo otro defecto de instrumentación: el clasificador reduce el log a128 líneas antes de buscar indicadores. Un error intermedio de un archivo menor al techo128KiB puede quedar fuera de la clasificación aunque sus bytes ya se hayan leído. La corrección local clasifica las ventanas de bytes admitidas sin ampliar el techo, emitir texto privado o convertir un indicador textual en causa comprobada. Las ventanas discontinuas de archivos grandes deben clasificarse por separado para no fabricar un estado HTTP al unir fragmentos.

La corrección diagnóstica no modifica inferencia, permisos, prompts, límites ni validación de resultados. Sus439 pruebas Windows terminan con437 correctas y dos omisiones históricas. El servicio conserva su código cargado anterior: esta corrección local no se presenta como desplegada ni como solución al timeout.

El observador externo de prueba sólo lee el marcador, manifiesto y ventanas acotadas del log del intento propio. Comprueba identidad, ownership, baseline vacío, inodos y política antes y después de leer; no abre credenciales ni emite texto del log. El vínculo con el directorio temporal combina el marcador exacto, admisión exclusiva del perfil, directorio nuevo y política coincidente; no existe un ID de intento firmado en el nombre del directorio. Pasan15 controles Linux de aislamiento y cierre, además de los controles sintéticos del driver Node. La lectura externa evita reiniciar el servicio e invalidar sus pruebas de modalidades.
